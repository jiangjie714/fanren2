日期：2026-10-16 ｜ 状态：已拍板（主题「星陨天墟」+ 曲线沿用 M24 分段续爬） ｜ 前置：M24 罡风天壑（`98a15e3`）

## 1. 背景与问题

妖径（#47）已 8 章。第八章（M24）已把 battle 曲线从「触顶」改成「无封顶续爬」，
拼图 60s / 三消 HP 38 两个触点是**刻意标定**（人类操作下限与 0.44 通关率甜点），记录不改。
因此本章**不动任何曲线公式**，纯粹是**内容续产**：数据表 +1 章 + 7 只新妖 + 主题背景。

主题上一路走「地 → 谷 → 洞 → 血 → 冰 → 雷 → 炎 → 风」，五行地象已用尽，
第 9 章换成**天象**：星陨、流光、天墟。视觉上从「地表元素」抬到「夜空星煞」，
同时避开与既有八章配色撞车（前八章：绿 / 雾青 / 土褐 / 血红 / 冰蓝白 / 紫电 / 橙红 / 青灰）。

## 2. 曲线：零改动

```ts
export function chapterScale(chapter: number): number {
    return chapter <= 7
        ? Math.min(1.8, 1 + (chapter - 1) * 0.15)   // 存量口径，bit-exact
        : 1.8 + (chapter - 7) * 0.15;               // 第 8 章起无封顶续爬（M24）
}
```
